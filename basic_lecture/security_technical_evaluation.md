# セキュリティ技術評価
施したセキュリティ対策が、どの程度**セキュリティを担保**しているのかを評価すること
- 客観的な評価による見落としを防ぐ

## セキュリティ技術評価手法
- CVSS (Common Valunerability Scoring System)
  - 基本評価基準
  - 現状評価基準
  - 環境評価基準
  - 3基準で0.0~10.0でスコアリング、非ベンダー依存
- PCIDSS (Payment Card Industry Data Security Standard)
  - クレジットカード業界の情報セキュリティ国際統一基準
  - 12の要件を持つ
- 脆弱性診断
  - 脆弱性の有無を診断する
  - ツール診断
  - 専門エンジニアによる手動診断
- ペネトレーションテスト
  - 脆弱性を発見するために侵入を試みるテスト
- 耐タンパ性
  - 外部からのデータ改竄、読解、取り出しへの耐性度合いを示す
