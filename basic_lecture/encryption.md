# 共通鍵/公開鍵暗号方式
## 共通鍵暗号方式
- 通信する送受信者間で共通鍵を共有し、暗号化/復号化する
- 通信相手が増えるほど鍵は増加(n*(n-1)/2本)
- AES

## 公開暗号鍵方式
- 公開鍵と秘密鍵を受信者側が持つ
- 公開鍵をネット上に公開する
- 送信者は公開鍵を使って暗号化する
- 受信者は秘密鍵を使って復号化する
- 鍵の本数は2n本で済む
- RSA, ECC(楕円曲線暗号)
