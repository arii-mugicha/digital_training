# 個人情報の取り扱い
## 個人情報保護法
- 個人情報の定義
  生存する個人に関する情報で、特定の個人を識別できる情報
- 個人情報の取得、利用ルール
  利用目的を通知し、勝手に取得、利用しないこと

### 個人情報の取り扱い
- 個人情報の取得には**本人の同意**が必要
- 利用目的はあらかじめ**公表**または**本人に通知**する
  - **利用目的の範囲内**で利用
- 違法、不当な方法を助長、誘発するおそれがある方法で利用してはいけない
- 漏洩、紛失をしない
  - 人的安全管理措置
  - 組織的安全管理措置
  - 物理的安全管理措置
  - 技術的安全措置
  - 漏洩、紛失した場合は**個人情報保護委員会への報告**と**本人への通知**が義務
- 本人からの開示請求、苦情に対応する

### 用配慮個人情報
個人情報のうち、不利益が生じないように取り扱いに配慮すべきもの
- 本人の同意を得ずに事業者が第三者に提供できない(**オプトアウト**の禁止)
例：人種、信条、社会的身分、病歴、犯罪の経歴

### 匿名加工情報
特定の個人を識別できないように加工した個人情報。個人情報を**復元できない**
### 仮名加工情報
他の情報と照合しない限り特定の個人を識別できないように加工した個人情報。個人情報を**復元できる**
