# 無線LANのセキュリティ
有線LANに比べてセキュリティに気を付けるべきことが多い
- 外部からの不正利用
- ルータの管理画面への不正侵入
- 傍受による情報の窃盗

## 無線LANルータの設定
- 初期状態のID,PASSから必ず変更する
- ファームウェアの更新を行う
- 暗号化方式が古くないものにする

### 暗号化方式
- WEP
  - **脆弱性**がある
- WPA2
  - WEPの脆弱性に対応
- WPA3
  - WPA2から暗号鍵とユーザー認証を強化

## アクセスポイントフィッシング
悪意のある第三者が接続を誤るようなアクセスポイントを設置して、誤接続させる手法
