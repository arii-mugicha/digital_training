# ARP
IPアドレスからMACアドレスを獲得するプロトコルのこと

# サラミ法
不正行為が表面化しない程度に多数の資産から少しずつ搾取する

# スキャベンジング
メモリなどに残る情報をあさって入手する不正行為

# メールヘッダインジェクション
改行コードを悪用してメールヘッダや本文を不正に変更する

#ソーシャルエンジニアリング
社交的な、IT以外の技術を用いて不正に情報の獲得を行う不正の手段

# ISMS適合性評価
機密性、完全性、花王製を一定水準で確保する仕組みが整っていることを認定する

# 第三者中継
外部ネットワークから受信したメールの宛先が管理外のドメインの時に、そのドメインのメールサーバに対してメールを中継すること。

# Instruction Detection System
不正アクセスや攻撃を通信監視で行うこと

# IPsec
Internet Protocolを拡張してセキュリティを高めたプロトコル、通信相手を確認するAuthentication Headerと伝送データ暗号化を行うEncapsulated Payloadからなる。
