# PKI
Public Key Infrastructure
デジタル署名を利用して公開鍵のセキュリティを実現する

## 公開鍵認証の問題点
不特定多数の利用するネットワーク上では第三者が公開鍵を成りすまして配布している可能性がある。
配布している相手本人の公開鍵を入手する必要がある。

## PKIの仕組み

認証局(**CA**)と呼ばれる公開鍵の真正を証明する機関を利用する
1. 公開鍵を本人確認書類とともにCAに申請
2. CAの秘密鍵で暗号化した**デジタル証明書**を作成、サーバに送付
3. クライアント側が公開鍵を要求するときには、デジタル証明書を送付
4. デジタル証明書を認証局の公開鍵で復号できれば検証可能
