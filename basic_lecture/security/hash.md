# ハッシュ関数
- あるデータを一定のアルゴリズムで処理して別のデータにするもの
- 固定長出力であるものが多い
- ハッシュ値からの復元は不可能(不可逆)

## ハッシュ関数の利用
パスワード認証
- サーバーにパスワードのハッシュ値を保存
  - サーバ管理者からパスワードが見えない
  - 流出に対しても頑健
- 過去にSHA-1は衝突が確認

## ハッシュ値の不可逆性の担保
元データとハッシュ値の対応を記録したテーブル(レインボーテーブル)が存在すると、復元できる
- ハッシュ後の値から辞書的に元の値を探す

### ソルト
データにソルトと呼ばれる**文字列を付加**してからハッシュ値を求める
- 単純な文字列から予測困難なハッシュ値を作成する

### ストレッチング
データに対して何度もハッシュ関数をかけることでハッシュテーブルの算出にかかる計算量を増加させる

## ハッシュ関数のアルゴリズム
- MD5 (**脆弱性が指摘**されている)
- SHA-256
- SHA-512
