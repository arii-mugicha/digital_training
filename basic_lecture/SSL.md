# SSL
Secure Socket Layer
- 通信経路での不正を防止するためのプロトコル

## SSLの仕組み
- データのやり取りには共通暗号鍵方式を利用する
- 暗号鍵の共有に公開暗号鍵方式を利用する

### 手順概要
1. サーバの公開鍵を共有
2. 公開鍵で共通鍵を暗号化して共有、秘密鍵で復号

### 詳細な手順
1. クライアントがサーバに接続要求
2. サーバからクライアントに**デジタル証明書** (公開鍵を含む)を発行
3. クライアント側が**公開鍵**を取得
4. クライアントが**共通鍵**を生成し、公開鍵で**暗号化**
5. 暗号化した共通鍵をサーバに送付
6. **秘密鍵**を用いてサーバ側で共通鍵を**復号**
