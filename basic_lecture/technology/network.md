# ネットワーク
複数のコンピュータや機器をつなぐことで情報をやり取りできるようにした仕組み

## 用語
- インターネット
  - ネットワークが相互に接続した巨大なネットワークのこと
- 端末
  - インターネットに接続されている機器のこと
- IPアドレス
  - 端末に割り振られた番号のこと
  - 情報をやり取りする際に端末を識別する

## Webページへのアクセス
1. URL文字列を用いてアクセス
2. DNSサーバにIPアドレスの問い合わせ
3. DNSサーバがURLをIPアドレスに変換
   - サーバに接続されるルータのIPアドレス (**グローバルIPアドレス**) 
4. IPアドレスを端末に返戻
5. IPアドレスをもとにWebサーバにアクセス
   - ルータを経由して指定のサーバにアクセス (**ローカルIPアドレス**)
6. Webサーバから返戻

## LAN
Local Area Network
- プライベートIPアドレスで構成されたネットワークのこと
- LAN内の端末同士は**ハブ**や**スイッチ**を経由して通信
- LAN外の端末とは**ルータ**を経由して通信

## ポート番号
通信元端末がルータを経由してLAN外部に通信するとき、通信元はポート番号を指定する。  
通信先からの返戻については、ルータがポート番号に応じた端末に情報を渡す。
