# 利用者認証
通信相手の本人確認を行う、利用者がその人であると確認すること

## 利用者認証の分類
- 知識情報による認証
  - IDとパスワード
  - 秘密の質問
- 所有情報による認証
  - ワンタイムパスワード
  - ICカード
- 生体情報による認証
  - 指紋認証
  - 静脈認証
  - 顔認証

## 多要素認証
複数の認証を組み合わせる方式
- 複数の種類である必要性がある

## 具体的手法
RADIUS (Remote Authentification Dial User Service)
- クライアントサーバ間の認証や権限付与を行うプロトコル
- 利用者の情報をサーバに一元管理できる
- **無線LAN**などに利用
