# 情報セキュリティとは
情報のCIAを確保すること

## セキュリティの3要素
- 機密性: Confidentiality
  - **情報へのアクセス権限**を保護・管理すること
- 完全性: Integrity
  - 常に**正確な情報を維持**している状態
  - アクセス履歴、変更履歴を残す対策
- 可用性: Availavility
  - **必要な時**に、**必要な情報**にアクセスできる
  - システム/サーバの冗長化による障害対策

## セキュリティの7大要素
セキュリティの3要素に加えて以下の4要素を加える
- 真正性 (Authenticity)
- 責任追跡性 (Accountability)
- 信頼性 (Reliability)
- 否認防止 (Non-repudiation)

# 脆弱性 (セキュリティホール)
ソフトウェアやネットワークにおけるセキュリティ面の欠陥や弱点。
- 例
  - ソフトウェア、OSの欠陥
  - ファイアウォールの設定ミス
  - サーバの設定ミス
- 対策
  - セキュリティソフト
  - セキュリティパッチの適用
