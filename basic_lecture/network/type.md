# ネットワーク方式
## 通信方式
- アナログ通信
- デジタル通信

## ネットワークの種類
ネットワーク: 複数のコンピュータを接続して通信可能にしたもの。接続されたコンピュータなどを**端末**、**ホスト**と呼ぶ

### 通信のプロトコル
プロトコル: 送受信側のデータやり取りに関する決まり事
- TCP/IP
  - もっとも一般的なネットワーク通信プロトコル
- フレームリレー
  - データリンク層で動作する高速パケット通信プロトコル
  - 物理回線上に複数の仮想回線を構築する
- ATM
  - Asynchronous Transfer Mode
  - 53バイトの固定長データセルを通信
  - ベースにした通信方法が主体
- PSTN
  - 公衆交換電話網 (Public Changed Telepone Network)
  - 固定電話回線を基盤とする
  - 最寄りの電話局に接続し、交換機が回線を振り分ける
