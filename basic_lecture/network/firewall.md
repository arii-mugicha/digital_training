# ファイアウォール
組織のネットワークを外部から守る。  
**ルータとLANの間**に設置する。

|ファイアウォールの種類|TCP/IPモデル上の動作層|
|---|---|
|パケットフィルタリング型|インターネット層|
|サーキットレベルゲートウェイ|トランスポート層|
|アプリケーションゲートウェイ型|アプリケーション層|

## パケットフィルタリング型ファイアウォール
パケットのヘッダを参照し、送信元、宛先、宛先ポート番号をもとに通過させるパケットを識別する。  
メールサーバへのスパムメールやWebサーバへの不正データは防げない。

# DMZ (DeMilitarized Zone)
外部ネットワークと内部ネットワークの間に設置するサブネットワークのこと。  外部に公開するサーバを内部に設置しないことで、ネットワークを通じた被害を最小限に抑える役目がある。  
外部ネットワーク -*Firewall*- DMZ -*Firewall*- 内部ネットワーク  
となるような構造を取る。

# WAF (Web Application Firewall)
パケットのデータに含まれている通信内容を調べ、不正な操作が行われるようなデータが含まれるパケットを遮断する。  
Webサーバとローカルネットワークの間に設置する。

# VPN (Virtual Private Network)
## インターネットVPN
クライアントPC/社内サーバとWANルータの間にVPNゲートウェイを設置する。  
パケットに対してAH(認証)、ESP(暗号化)ヘッダを付与する。その後IPヘッダを付与する。  
パケットはインターネットを通じて送信され、届いた側のVPNゲートウェイが認証、復号化を行う。
