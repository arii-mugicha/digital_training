# ブラウザからWebを獲得する仕組み
1. クライアントからWebサーバにリクエストを送信
2. Webサーバからリクエスト結果のレスポンスを返答
   - HTTP/HTTPSプロトコルを利用

# Cookieとセッション
## Cookie
**ブラウザにデータを保存する**仕組み。クライアント識別のメモとして利用される。  
Webサーバのレスポンスや、クライアントからのリクエストとして一緒に送信することが出来る。
## セッション
**Webサーバに保管される**一時的なデータ。   
ユーザとのセッションIDをCookieとして保存させることで、クライアントを識別する際などに利用される
