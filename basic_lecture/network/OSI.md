# OSI基本参照モデル
システムの通信方式を画一化することで、異なる機種同士が通信できるようにする。CCITT(国際電信電話諮問委員会)とISO(国際標準化機構)によって規格化された。

## OSI参照モデルの解体
複数の層に分割することでコンピュータごとの差異を吸収する。
|層名|役割|
|---|---|
|アプリケーション層||
|プレゼンテーション層||
|セッション層||
|トランスポート層||
|ネットワーク層||
|データリンク層||
|物理層||
### カプセル化/非カプセル化
アプリケーション層から下に下がるたびにヘッダを付与し(復号処理の際に利用)、上に戻すときにヘッダを除去。  
他の層のヘッダは寄与しないため、層同士で接続しているかのようにふるまうことを**論理的接続**と呼ぶ。
