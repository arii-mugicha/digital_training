# 伝送制御 (Transfer Contrl)
1. 端末間に回線を接続
2. データリンクの確立(回線の**占有**)
3. データの送信
4. データリンクの解放
5. 端末間の回線の切断

# メディアアクセス制御 (MAC: Media Access Control)
データ同士が衝突したときの対処、衝突を防ぐ仕組み
## CSMA/CD
|略称|正式名称|役割|
|--|----|----------|
|CS| Carrier Sense | 搬出波感知 | 
|MA| Multiple Access | 多重アクセス |
|CD| Collision Detection | 衝突検知 |

1. 伝送路が空いているのかを確認
2. 空いているのならばデータを送信  
  a. データの衝突を検知  
  b. データの送信の一時停止  
  c. 伝送路が空いているのかを確認し、ランダム時間後に送信  
3. 受信完了の合図を取得

## CSMA/CA
主に無線LANアクセスポイントで用いられる
|略称|正式名称|役割|
|--|----|----------|
|CS| Carrier Sense | 搬出波感知 | 
|MA| Multiple Access | 多重アクセス |
|CA| Collision Avoidance | 衝突回避 |

アクセスポイントほかの機器と通信中は待機し、通信がなくなると送信するようになる
