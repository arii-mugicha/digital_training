# IP(Internet Protcol)の役割
1. IPアドレスの設定
2. パケットを届けるためのルーティング(経路制御)

# IP Address
ホスト、ルータの識別子。ホストには1つ以上、ルータには2つ以上を割り当てる。  
- 32bit(8bit.8bit.8bit.8bit)
- ネットワーク部とホスト部からなる
  - ネットワーク部: IPアドレスがどのネットワークに属しているかを表す
  - ホスト部: ネットワーク内のどのホストかを示す
## 特定のIPアドレス
ホストやルータに割り当てられないアドレスが存在
### ネットワークアドレス
ホストの属するネットワークを示す。ホスト部がすべて0。
### ブロードキャストアドレス
ネットワーク内のすべてのホストにパケットを送信するアドレス。ホスト部がすべて0。

# サブネット分割
## サブネットマスク
IPアドレスとの論理計算を行うことで特定の値を取得することが出来るもの。ネットワーク部とホスト部の範囲を表す。  
`255.255.255.0`のように論理積を取って標記するものと`198.51.100.123 /24`のように桁数を指定するプレフィックス標記がある。

## サブネットマスク
ホスト部の一部をネットワーク部として取り扱うために、サブネットマスクやプレフィックス標記を用いて、効率的にネットワーク部/ホスト部を動的に扱う。

## CIDR (Class Inter-Domain Routing)
IPアドレスの規模を動的に割り当てる方式
