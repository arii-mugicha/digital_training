# 情報セキュリティリスクへの対応
代表例6つ
- リスク低減
  - リスクの発生する可能性、発生時の**被害を最小限**に抑えること
  - **暗号化**による流出時の被害回避
  - 所属人員への**教育**によるインシデント発生率の低下
- リスク回避
  - リスクの要因となるものを取り除くこと
  - リスクとリターンを天秤にかけてリスクを重視しリスクあるシステムの仕様を控える
- リスク移転
  - 発生する恐れのあるリスクを**第三者に移転**すること
  - **保険**への加入によるリスクへの準備
  - 機密データの**パブリッククラウドへの保存**
- リスク保有
  - リスクを認識したうえで発生時の**損害を受容**すること
  - 発生頻度の著しく低いもの
  - 対策コストが損失コストを上回るもの
- リスク分散
  - リスクを複数に分割すること
- リスク集約
  - 複数の**リスクを組み合わせて**扱いやすい単位にする
  - 出入口を一本化するなど

# リスクアセスメント
リスクが顕在化する前に評価を行い、対応すべき優先順位付けを行う。
以下の三つの手順からなる。
- リスク特定
  - 将来のリスクを想定する
- リスク分析
  - 特定したリスクの発生率と発生したときの被害を見積もる
- リスク評価
  - リスク分析の結果から優先順位をつけ、対応を決定する
